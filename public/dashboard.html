Dashboard

Total stock of every Commissary meat, across Commissary itself plus whichever restaurants you pick - so management can see "do we need to order more of this" without a spreadsheet. Restaurant columns reverse-convert a restaurant's own portioned stock back to a Commissary-meat-equivalent using the Conversion Standards set up in Settings - a meat with no standard for a restaurant simply isn't counted under that restaurant's column for that row, same as it isn't tracked as coming from Commissary at all.
