# ADR-032 Grouped navigation, after table-scroll

- Status: Accepted 2026-10-21
- Decided by: Naoki
- Supersedes: none

## Context

The prototype grouped the pages as Tonight / Supply / Staff / Management.

## Decision

- Navigation follows the prototype's groups.
- It touches every page, so it goes after table-scroll (issue #30), which goes after ui-pass-ii.

## Why

Staff find tonight's work first.

## Consequences

Both are listed under Planned in the queue.

## Reopen only if

Staff testing shows the groups confuse people.
